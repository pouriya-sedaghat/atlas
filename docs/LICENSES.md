# Seyra Map Services — licence and provenance inventory

Status: inventory for phase 1, built from the files and lockfiles actually used. It is **not legal advice** and draws no conclusions about distribution obligations; those depend on how the owner distributes the images and bundle, and remain an open owner/legal review item (see "Open items").

The machine-readable identities are in `infra/dependencies.lock.json`: sources with full commits, artifact SHA-256 values, image IDs, base-image digests and npm integrity. That file is authoritative; this page summarises it.

Map assets generated at build time (`packages/map-assets`):
- **Fonts and glyphs:** Vazirmatn 33.0.3 Regular and Bold (SIL Open Font License 1.1). The woff2 files are served unchanged. The SDF glyph PBFs are derived renderings, produced with opentype.js 2.0.0 (MIT) and a port of TinySDF (BSD-2-Clause). The OFL text is served at `/licenses/vazirmatn-ofl.txt` and shipped in the proxy image.
- **Sprites:** generated by project code; no third-party artwork.
- **Styles:** generated by project code (`seyra-style-1.0.1`).

Development and test tooling, not shipped in runtime images except where a build stage needs it:
- TypeScript 6.0.3 (Apache-2.0), Vite 8.3.4 (MIT), vitest 5.0.4 (MIT).
- Playwright 1.56.1 (Apache-2.0), preinstalled in the preparation environment and used only for browser evidence.

## Open items for the owner

- AGPL-3.0 (Overpass API) and GPL (osm2pgsql, osmium-tool, Nominatim, PostGIS) obligations if images or the offline bundle are distributed outside the owner's organisation: source offer, corresponding source, network-use clause. Source commits are recorded, and `infra/prepare/fetch-sources.sh` reproduces the exact source trees. No legal conclusion is drawn here.
- ODbL obligations for any produced work or derived database shared outside the organisation.
- Debian 11 base of `postgis/postgis:17-3.5`: confirm an acceptable support window, or move to a newer pinned PostGIS image in a later preparation cycle.
